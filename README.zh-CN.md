[English](README.md) · **简体中文**

CodexBuddy 为 Codex / ChatGPT 增加一个随手可用的辅助面板：快速定位长回答，生成下一步问题，留在对话内或弹到桌面使用。

从左侧栏的眼睛入口打开工作台，悬停可选择“内／外／设置”，单击默认动作可配置。双击或 Alt+Enter 在聊天与桌面之间切换主界面；右键在 ChatGPT 内置浏览器侧栏打开设置。桌面窗口右上角提供收回聊天、放大／还原和置顶，默认置顶并记住选择。

术语释义可在设置的“功能 → 术语释义”中开启：导入本地词库后，聊天中的术语以加粗文字和下划线标记，悬停查看中文解释，也可标记为已掌握。正文悬停和侧栏点击共用贴字浮层，颜色跟随主题，可选哑光、磨砂、液态、纯黑或自定义背景；支持收藏、手动添加及文档导出。可选的语义识别将当前一问一答发送到配置的模型；联网补充仅查询短术语，结果不写回主聊天。词库保存在本机，未内置于分发包。

工作台新增“术语”页签，用小标签查看当前聊天涉及的概念，并独立管理收藏和已掌握。语义片段可跨段落与文字格式定位；分析结果缓存，失败有限重试。

在“设置 → 功能 → 术语释义”开启“点击术语时跳转到上下文”后，点击术语会定位并短暂突出当前聊天中最近一次已确认的出现位置，同时保留释义浮层。开关默认关闭；找不到有效位置时提示失败，不切换聊天。

## 能做什么

| 功能 | 用途 |
| --- | --- |
| 回答大纲 | 点击标题定位并高亮原文 |
| 下一步建议 | 根据当前回答生成后续问题，复制或填入输入框 |
| 停靠工作台 | 大纲与下一步同时显示，聊天让出空间；支持自动、上下或左右排列，可拖拽编排、合并标签或专注查看，分别记住停靠与浮窗布局 |
| 桌面浮窗 | macOS 15+ 可在内嵌与弹出之间切换，支持拖动、调整大小和置顶 |
| 模型快切 | 独立功能，支持四种呈现形式，切换官方聊天模型、推理强度与速度，保存完整预设；不改变下一步建议的模型配置 |
| 任务看板 | 默认待办、进行中、完成；支持分组改名、新增与拖放，窄侧栏标签切换，宽窗口并排显示 |
| Apple 提醒事项集成 | 实现和已有数据保留，当前暂不提供设置入口 |
| 术语释义 | 本地词库、语境释义、收藏与已掌握管理 |
| 提示词优化 | 改写当前草稿，可取消或还原，不自动发送 |
| 阅读与外观 | 跟随 Codex 字体或使用固定字号，调整材质与摘要显示 |
| 自选模型 | 使用现有 Codex 登录，或连接自己的模型 API |

大纲在本机解析，无需模型；下一步建议需要配置模型。两个功能可以分别关闭。

在 Web 设置中选择 **设置 → 生成 → 生成模型 → 高级设置 → 输入上下文 → 最近一次聊天（完整）**，即可使用完整的最近一次提问与回答，不做本地字符截断。新配置默认采用此模式；已有字符上限保持原值，也可继续自定义。实际输入仍受所选模型上下文窗口限制。建议保持完整目标和授权边界，不把相关待办机械拆成按钮；输出可独立发送的中文提问，技术名称可保留原文。

**建议方向**与自动/手动生成时机独立：

- **自动探索**：一次生成请求自由发现方向，最多返回设定条数。
- **我来选择**：选择并排序方向位置，一次请求按位置生成，每个方向最多一条；不适用则跳过。
- **智能挑选（实验）**：Jev 仅作为候选方向的适用性判别器，一次批量判断已启用方向是否适合当前上下文；不负责开放式方向探索、建议或 Prompt 生成，也不执行操作。用户配置的生成模型再选择互补方向并撰写具体提问。需要独立 TypeSafe 密钥，并明确同意发送最近一问一答。其他模式不调用 Jev，失败不静默切换模式。

Web 设置提供六个可编辑预设及自定义方向。数量是上限，允许少给或为空。新配置默认最多三条，旧配置保留条数和生成时机。显式设置输入上限时优先保留用户问题，标明截断；Jev 与生成模型使用同一上下文快照。Jev 的适用性门槛仍为实验值，尚未经过建议质量校准。

鼠标移到独立眼睛入口，可选择“内”“外”或“设置”；默认单击动作在“界面 → 外观与字体”调整。工作台顶部不再重复显示表情。桌面窗口右上角提供横线形状的收回聊天、放大／还原及置顶按钮。放大使用屏幕可用区域，点击还原回到原来的位置和尺寸。

工作台中，拖动面板标题或标签到另一面板边缘可分栏，拖到中央可合并标签；双击标题或标签临时放大面板，再双击标题或按 Esc 恢复；键盘可聚焦标题后按 Enter 或空格。完整编排选项保留在 Web 设置页。拖动时按 Esc 可取消。

大纲与下一步始终使用同一聊天来源，顶部来源文字及跟随／锁定菜单暂时隐藏，已有的关联状态保留。来源暂不可用时保留已有结果供查看，恢复后继续使用。

## CodexHost 管理

设置“设置 → 系统 → 宿主管理”提供安装/运行版本、启停选择、检查更新、版本安装/回退和显式重启停用。开关保存下次启动意愿，重开仍遵循现有启动策略；管理功能不要求启用Buddy MCP插件。

## 提示词优化

在设置“功能 → 常用开关”中可启停提示词优化。设置页顶部搜索可跨分类查找并定位控件，也可用 `⌘K`（或 `Ctrl+K`）聚焦搜索。

在聊天输入框中写好草稿，点击工具栏带星光的笔图标，结果会替换草稿，不会发送消息。处理中可点击“取消”；完成后可“还原”。继续输入或切换聊天会使旧请求失效；含特殊引用节点时保留原文。使用 Buddy 设置中“设置 → 生成 → 生成模型”的现有模型与凭据，只读取当前输入文本，不携带聊天历史。

## 设置导航

设置统一使用“功能、生成、界面、系统”四组导航，无需切换简易或详细模式。常用开关、下一步、常用提示词、术语释义、任务看板和模型快切分别配置，布局位置与外观字体也分开。宽屏左侧显示分组和子页；760px及以下使用顶部两级导航，先选分组，再选子页。切换页面保留未完成编辑和阅读位置；高级设置、词库管理和模型分组从右侧抽屉打开，关闭保留输入与滚动位置。现有配置、密钥及旧设置链接保持兼容。生成模型同时用于下一步建议和提示词优化。

设置页采用 Tom Modern 设计，提供工作空间、功能、生成路径和连接状态的联动预览。保存位置、嵌套分栏或材质后，工作空间示意随之更新；生成预览会标明未保存编辑。示例操作仅在预览内生效。页面默认跟随 Codex 的深浅主题，也可从页头主题入口固定浅色或深色并记住选择，品牌图标保持原图。继续尊重减少动态效果和已有统一字体设置。

## 任务看板

在“功能 → 常用开关”中开启看板，设置的“功能 → 任务看板”管理分组；也可以运行 `codex-buddy board`。默认待办、进行中、完成三组，分组名称和新增分组在设置页管理。侧栏通过分组标签切换，宽窗口并排显示。

Apple 提醒事项的授权、列表选择和同步入口暂时隐藏，当前主要使用本地看板。实现代码、已有绑定及任务数据保留；隐藏入口不会删除 Apple 提醒事项，也不会自动重置已有同步配置。旧“等待”任务归入待办显示，原阶段数据保留。

设置连接凭据在同一后台地址的浏览器标签页间共享。新标签、刷新或重新打开页面可沿用已建立的连接；凭据过期或后台地址改变时，从眼睛菜单重新打开一次设置。同地址下其他标签页随后自动恢复，未保存的表单不会因此卸载，保存操作不会自动重复提交。

### 功能与显示位置

CodexBuddy 使用左栏独立眼睛入口，不依赖插件。单击收放工作台，双击或 Alt+Enter 保持窗口往返；右键或 Option＋右键在 ChatGPT 内置浏览器侧栏打开设置。

在 Web 设置“界面 → 布局与位置 → 主界面”中选择侧栏、页面浮层或可调整大小的桌面窗口，三者只保留一份。大纲、看板、下一步、模型快切和术语各自选择加入主界面或贴边/刘海；主界面共用标签，贴边可独立共存。四种形式分别保存纯黑、哑光、磨砂、液态（Regular/Clear）主题。眼睛入口收放主界面，双击整组弹出/返回；设置页唤起复用已有窗口。切换位置保留草稿、功能关闭状态和任务数据。

设置的“界面 → 外观与字体”默认跟随 Codex 聊天正文，术语卡片、工作台和设置页共用。可改为跟随左侧会话标题或输入框文字，调整相对大小（75–150%），也可使用固定自定义字号（10–32px）。切换聊天或暂时找不到跟随对象时保留最后有效字体，旧的分功能字号值仍保留在配置中。

进入独立模式前，先收回已有的桌面工作台。换位置保留本次服务会话的阅读状态和组内新建草稿，无需先退出编辑。关闭视图不关闭业务服务或提醒事项同步。桌面窗口要求 macOS 15+。

默认分组为“待办、进行中、完成”，可修改名称或新增分组。卡片只展示标题，各组底部直接新建；宽窗口拖到另一列，窄侧栏拖到目标分组标签。悬停卡片显示垃圾桶，点击直接从 Buddy 删除；Apple 提醒事项保留，后续同步不再导入该项。卡片不弹出详情，搜索按需展开。自定义分组仅存本地，进入完成组仍同步完成状态。

首次将旧独立看板迁入独立功能模式时，先保存草稿并关闭旧窗口；未处理前会保留旧窗口并提示，不自动结束进程。

鼠标移入眼睛入口，会展开“内／外／设置”在侧栏内部向上展开的无背景菜单：内是聊天内工作台，外是桌面浮窗，设置在内置浏览器侧栏打开。“界面 → 外观与字体”可选择单击默认动作，旧配置默认“内”并保持收放。键盘方向键可打开并选择菜单，Esc 关闭；Alt+Enter 保留窗口往返。动画尊重系统减少动态效果设置。

独立眼睛入口会显示原胶囊的空闲眨眼、生成中、完成和错误等表情。多个聊天同时可见时，按钮边缘的小点指示当前关联聊天的方向；单聊天或来源无效时隐藏。不会恢复额外的胶囊，点击及展开菜单操作不变。

侧栏工作台和桌面浮窗顶部不再重复显示胶囊眼睛；操作集中在独立眼睛入口。桌面保留拖动条、置顶和 Alt+Enter 收回快捷键。

## 操作流程与状态切换

眼睛入口常驻宿主左侧栏，工作台和桌面窗口顶部不再重复显示。

| 操作 | 结果 |
| --- | --- |
| 单击眼睛 | 执行保存的默认动作；旧配置默认收放聊天内工作台 |
| 悬停后选择“内／外” | 打开保存的聊天内位置，或唤起已有桌面窗口 |
| 双击眼睛或按 Alt+Enter | 在聊天与桌面之间切换主界面 |
| 点击桌面窗口的横线按钮 | 将主界面收回聊天 |
| 右键眼睛或选择“设置” | 在内置浏览器侧栏打开设置 |
| 拖动标题／标签；双击标题／标签 | 分栏或合并；临时放大面板，按 Esc 恢复 |

收起时释放侧栏空间并保留位置偏好；空间不足时保持关闭，空间恢复后手动重新打开。侧栏与页面浮层在设置中选择；桌面放大后可还原普通窗口的位置和尺寸。

## 安装与使用

### 1. 安装

准备好 ChatGPT / Codex 桌面应用，以及 Node.js 22.16+、Rust 1.88+、Xcode Command Line Tools。

从 [Releases](https://github.com/0xTotoroX/codex-buddy/releases) 下载并解压 GitHub 自动生成的 **Source code (zip)** 或 **Source code (tar.gz)**，在项目目录执行：

```sh
npm ci
npm run install:local
```

安装完成后，在「应用程序」中双击 **CodexBuddy**。日常使用无需 Node.js 或 Rust。

> ChatGPT / Codex 已打开但没有调试连接时，CodexBuddy 默认先询问，再正常退出并重开。可在设置页「启动行为」改为「直接强制重开」，但可能中断任务或丢失未保存内容。已有可用调试连接时直接接入。

### 2. 配置模型

从眼睛入口打开设置，在「设置 → 生成 → 生成模型」选择「现有 Codex 登录」或填写自己的模型 API，输入完成后离开输入框会自动保存，选项切换即时保存；也可点击「保存设置」立即保存，再「测试连接」。使用现有登录需要本机有可用的 Codex CLI 和登录状态。

智谱 BigModel 选择 **Chat Completions**，API 地址填写 `https://open.bigmodel.cn/api/paas/v4`，再填写自己的密钥和模型名称。`glm-4.5-air`、`glm-4.7`、`glm-4.6v`、`glm-4.1v-thinking-flashx` 已通过固定示例的连接与建议格式校验。Buddy 自动适配智谱官方端点的请求格式，仍校验方向和输出内容；具体模型权限与额度取决于账户。「测试连接」会用固定示例生成建议，不读取当前聊天。

主界面在侧栏、页面浮层和桌面窗口中三选一，贴边／刘海面板可以独立共存。上下、左右、标签和临时放大只改变内部排布，不创建额外主窗口。面板刷新在鼠标进入工作台或键盘聚焦时显现，触屏保持可见。

### 3. 开始使用

- **看大纲**：切换到「大纲」，点击标题跳转到原文。
- **常用提示词**：下一步面板默认提供「继续」「执行」，点击只填入、不自动发送。Web 设置中「下一步 → 常用提示词」可编辑按钮名称和内容、添加或删除；不消耗模型请求，也不占建议名额。
- **继续提问**：在「下一步」点击刷新生成建议，也可开启自动生成。默认点击只填入，不自动发送；已有草稿时会询问是否追加。
- **编排功能**：在显示设置选择主界面位置，以及各功能加入主界面或贴边。拖动标题分栏或合并，拖动侧栏边缘与内部分隔线调整大小。关闭视图会保留服务和位置偏好。
- **调整窗口**：从眼睛菜单或用 Alt+Enter 切换窗口。拖动桌面窗口顶部移动、下角调整大小；横线按钮收回聊天，放大／还原与置顶分别保留偏好。Buddy 跟随 Codex 外观，不修改 Codex 颜色。

模型快切在设置页「模型快切」中启用，或运行 `codex-buddy model-control`。默认使用通用贴边形式，之后按保存的位置打开。保留常用模型、模型/推理/速度切换和预设；不改变下一步建议的模型配置。点击预设栏加号右侧的目录图标后，同一面板切换为按厂家排列的全部模型积木，关闭后恢复矩阵与收藏；已常用的模型也保留在列表中；点击积木加入或移出常用，以中性背景区分状态。刷新在目录关闭按钮旁。贴边窗口按常用模型的实际行数增高；表头闪电单击切换 Fast，并播放一次向下电流；下方细分隔线独立负责拖动调宽，拖动不会切换 Fast，减少动态效果时仅保留短暂明暗反馈。预设为独立内凹标签，无外层背景框，仅 Fast 预设显示闪电；末尾加号直接以模型名保存当前配置，无需确认，重名自动补序号，同一模型仍可保存多个预设，标签自动换行。铅笔切换编辑模式，所有标签左上角显示删除叉号，此时点击名称进入改名，普通模式单击仍应用预设。在 Web 设置的“功能 → 模型快切 → 模型分组”中，可纠正厂家、创建自定义组、批量移动、调整组和模型顺序或恢复自动分类。刷新保留手动整理与暂不可用模型的偏好；同名不同 ID 的模型保持独立。思考列只展示常用模型实际支持的档位。名称列扩大宽度预算，分隔线支持鼠标和键盘，到达思考标题的可读边界即停止。拖动期间外框保持稳定，松手后按换行适配高度；超过屏幕可用空间时才滚动整体内容。

贴边/刘海现为所有功能共用的形式。设置页“界面 → 布局与位置”管理显示器、边缘、位置和保持展开，“界面 → 外观与字体”管理主题。悬停展开，离开约半秒收起；点击进入键盘操作，`⌘⇧M` 切换展开/收起，编辑和业务操作期间不自动收起。收起或切换标签保留草稿。屏幕可选择“跟随 Codex”，让面板随 Codex 窗口移动到对应显示器；也可固定到指定屏幕。面板跨 Spaces/全屏显示，不随其他应用焦点跳动；停止 Buddy 后退出。

模型能力来自宿主实际列表。新聊天在发送第一条消息前也能切换模型。点击配置会在一次操作中读取、应用并回读确认；目标不明、能力未知或官方控件禁用时不会执行。生成期间允许调整后续配置，无需为等待能力列表而重启正在工作的宿主。旧模型视觉偏好自动迁到 surfaces.json，置顶和预设保留在 model-control.json。

## 更新与卸载

更新时获取新版源码，重新执行 `npm ci` 和 `npm run install:local`，原配置会保留。

卸载时先执行：

```sh
~/.local/bin/codex-buddy stop
```

再删除 `/Applications/CodexBuddy.app` 和 `~/.local/bin/codex-buddy`。如需同时清除配置，再删除 `~/Library/Application Support/codex-buddy/`。

## 二次开发

技术栈：**Rust + JavaScript / TypeScript + React**。

```text
src/          后台、CLI 和原生窗口
ui/features/  看板、大纲、下一步、模型快切、术语内容
ui/terminology/ 正文标注与释义浮层
ui/surfaces/  共用工作台、嵌入、桌面、贴边和主题
ui/codex/     Codex 页面读取、定位和输入适配
ui/shared/    共用契约、通信、图标和基础变量
ui/settings/  设置网页
tests/        自动测试
scripts/      开发、构建与安装工具
```

安装依赖后，先通过 CodexBuddy 打开宿主，再运行：

```sh
npm run dev
```

也可执行一次 `npm run install:dev`，安装独立的 **CodexBuddy Dev.app**。双击后在后台启动，保存源码自动更新，不弹出终端；重复打开会唤起已有工作台。没有调试连接时按开发设置页「启动行为」处理，首次使用继承日常设置。后台开发可用 `npm run dev:stop` 退出，日志在 `target/dev/launcher.log`。异常退出后，仅在监督进程和关联后台均已退出时自动恢复失效占用记录；无法确认时保留记录并提示具体原因。它依赖本机源码和开发工具；修改开发脚本或依赖后需停止并重新打开，移动源码或更换 Node 路径后需重新生成入口。

此前开发的官方插件页签联动保留为默认停用的试验。日常和 Dev 均使用原工作台入口，不随聊天切换自动展开官方分栏。

多个 Git worktree 可通过 `npm run dev:settings` 或旧眼睛入口右键打开开发设置，在同页「开发」分类切换来源（旧 worktree 保留顶部入口）；`npm run dev:settings` 打开同一页面并携带连接凭据。升级开发脚本后，正常停止并重开一次 Dev。未包含统一入口修复的历史 worktree 仍使用原齿轮地址，可从已有 Dev 设置标签页切回。切换会同时更换后台、设置界面与热更新来源，保持设置地址，不重启 Codex，并记住最后成功的选择。各 worktree 保留独立配置；编译失败保留当前来源，接入失败尝试恢复原来源。同一目标窗口使用一个 Dev 监督进程；迁入此流程前，先正常退出旧的独立 Dev 会话。也可用 `npm run dev -- --source /path/to/worktree` 显式指定启动来源。

从 Dev App 新建的后台会话会在确认 ChatGPT 主进程退出后自动清理；页面短暂断连不会结束会话。脚本升级后先运行 `npm run dev:stop`，再打开 Dev App；ChatGPT 可保持打开。

开发模式连接真实 Codex；修改界面后自动加载，修改 Rust 后自动编译。命令行启动时按 Ctrl+C 结束。开发配置独立，不覆盖日常安装；内嵌液态与正式版共用 SVG 渲染。

```sh
npm run verify         # 运行检查
npm run verify:web     # 前端与合成浏览器试点（也可在 Linux 运行）
npm run build          # 编译程序
npm run package        # 生成 CLI 程序包和发布校验说明
npm run install:local  # 将当前代码安装到本机
```

前端试点先执行 `npm ci`，必要时通过 `CHROME_PATH` 指定已安装的 Chromium；Linux 自动复用存在的 `/usr/bin/chromium`。日志与结果位于 `target/reports/web-pilot/`。Node 许可集成测试仍需 Cargo 及其依赖，缺少前置条件仍报告失败。试点排除原生检查，不替代完整验收，也不代表应用支持 Linux。

构建、打包不会自动更新已安装程序。提交问题或改进时，请附版本、系统和复现步骤，并移除密钥与私人聊天内容。

README 默认使用英文；更新用户文档时，请同步 [README.md](README.md) 与本中文版。

设置统一从独立眼睛快捷菜单或其右键入口打开，工作台顶部不再显示单独齿轮。设置使用 ChatGPT 内置浏览器中的完整本地网页，不依赖插件。
