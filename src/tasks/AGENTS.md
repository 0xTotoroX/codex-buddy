# tasks/ — 本地任务看板与提醒事项同步

> L2 | 父级：[AGENTS.md](../AGENTS.md)

看板和同步分别启停，与模型快切、Codex 会话和模型请求无业务依赖。一个可写列表同步 title/notes/completed；column 和 archived 属于本地，旧 due/priority 保留但不再同步。tasks.json 原子保存本地 UUID、字段、上次同步快照、冲突和在途意图。归档和删除只影响本地，不提供双端删除；remove 移除任务并持久保存远端身份，后续同步不再导入，删除在途任务需先完成核对。远端消失保留恢复记录，身份不明、读取失败与授权撤销不推断删除。重复任务保留规则，共享字段只读，可本地归档。

- [model.rs](model.rs)：纯任务结构、删除记录的远端身份（不保存正文，旧文件默认空）、可改名的稳定分组 ID（旧文件缺省三组）、单列表绑定、日期校验及三个共享字段合并/写入意图判断；远端身份仅使用唯一 ID/外部 ID/本工具创建标记。
- [mod.rs](mod.rs)：schema 1→2 自动暂停、原文件恢复副本、任务与在途创建身份保留、旧删除意图停止；任务存储、分组新增/改名与任务分组存在校验、修订保护、模块与窗口生命周期、持久化待同步变更、15 秒完整核对及冲突恢复；同步启动和重新开启先读后写。
- [native.rs](native.rs)：辅助 App 的单进程 EventKit 执行上下文、显式授权、选定列表读取、原对象局部更新及写前核对；通过公共 API 保留未编辑字段，不跨线程传递原生对象。
- [bridge.rs](bridge.rs)：以 LaunchServices 启动固定身份的私有辅助 App，以原生源码、依赖及构建输入和应用身份校验缓存，使用程序副本、用途声明、本地签名和 0600 文件通信；开发身份按工作目录隔离，正式身份固定；仅主动启用时创建辅助应用。
- [window.rs](window.rs)：可调整大小的独立 Tao/Wry 窗口、单实例唤起与租约退出；关闭窗口不改变同步或模型快切开关。
- [tests.rs](tests.rs)：合成数据的字段合并、身份变化、单列表迁移、归档不删远端、本地阶段不参与同步、日期、存储损坏及重启恢复回归；不访问 EventKit。

EventKit 没有跨设备 compare-and-swap：写前回读缩小竞争窗口，但不能承诺系统级事务隔离。创建结果不明时保留意图并对账，不自动重试产生副本。辅助 App 使用本地签名，正式签名、公证及跨版本 TCC 行为需要分发验收。窗口大小与卡片排序仅保留本地；窗口尺寸不推进业务修订。删除和异常处理同时核对任务原快照，防止最新修订掩盖同一任务的外部修改。旧三列表任务需先在 Apple 移入唯一目标，再显式绑定；绑定不搬移、不解绑远端身份、不复制缺失任务，首次绑定允许保留待核对创建。失效单列表只可暂停后在原账户修复；重新启用先对账。原生更新只写共享三字段，只有创建设置目标列表，不写日期/优先级。

[PROTOCOL]: 结构或契约变化时同步本文与父级地图。

view_command 是宿主内嵌看板的任务操作白名单，拒绝权限、列表映射、模块及原生窗口管理；board_enabled 只投影开关，视图位置不会更改同步开关。

close_window 只回收旧独立看板窗口，由新功能 ready 调用；任务存储、同步工作线程与开关保持独立。
