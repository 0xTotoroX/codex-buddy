# tasks/ — 本地任务看板与提醒事项同步

> L2 | 父级：[AGENTS.md](../AGENTS.md)

看板和同步分别启停，与模型快切、Codex 会话和模型请求无业务依赖。三个列绑定同一账户下不同的可写列表；用户确认 iCloud 来源，完成列聚合。tasks.json 原子保存本地 UUID、字段、上次同步快照、冲突和在途意图。归档只影响本地；永久删除明确作用于两端。远端消失保留恢复记录，身份不明、读取失败与授权撤销不推断删除。重复任务保留规则且仅查看/归档。

- [model.rs](model.rs)：纯任务结构、列表绑定、日期校验及三方字段合并；远端身份仅使用唯一 ID/外部 ID/本工具创建标记。
- [mod.rs](mod.rs)：任务存储、修订保护、模块与窗口生命周期、持久化待同步变更、15 秒完整核对及冲突恢复；同步启动和重新开启先读后写。
- [native.rs](native.rs)：辅助 App 的单进程 EventKit 执行上下文、显式授权、选定列表读取、原对象局部更新及写前核对；通过公共 API 保留未编辑字段，不跨线程传递原生对象。
- [bridge.rs](bridge.rs)：以 LaunchServices 启动固定身份的私有辅助 App，以原生源码、依赖及构建输入和应用身份校验缓存，使用程序副本、用途声明、本地签名和 0600 文件通信；开发身份按工作目录隔离，正式身份固定；仅主动启用时创建辅助应用。
- [window.rs](window.rs)：可调整大小的独立 Tao/Wry 窗口、单实例唤起与租约退出；关闭窗口不改变同步或模型快切开关。
- [tests.rs](tests.rs)：合成数据的字段合并、身份变化、删除冲突、日期、存储损坏及重启恢复回归；不访问 EventKit。

EventKit 没有跨设备 compare-and-swap：写前回读缩小竞争窗口，但不能承诺系统级事务隔离。创建结果不明时保留意图并对账，不自动重试产生副本。辅助 App 使用本地签名，正式签名、公证及跨版本 TCC 行为需要分发验收。窗口大小与卡片排序仅保留本地；窗口尺寸不推进业务修订。编辑器同时核对任务原快照，防止最新修订掩盖同一任务的外部修改。失效列表只可在暂停且无未确认创建时显式修复，保持原账户及正常绑定；待确认更新/删除保留意图，换绑后先对账；修复后先对账，缺失任务保留恢复记录。截止日期不自动创建通知闹钟。

[PROTOCOL]: 结构或契约变化时同步本文与父级地图。

view_command 是宿主内嵌看板的任务操作白名单，拒绝权限、列表映射、模块及原生窗口管理；board_enabled 只投影开关，视图位置不会更改同步开关。
