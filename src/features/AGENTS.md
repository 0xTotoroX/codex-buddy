# features/ — 共享主界面

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `main_surface.rs`：由 features.rs 调用，读取并迁移主界面偏好，管理唯一桌面子进程与 main lease；全部非贴边功能统一位置，来源快照和全部目标 ready 后整组提交，失败恢复原归属并保留关闭状态；最后一个桌面成员交出后同步回收旧窗口/租约，避免快速重开复用正在退出的进程。按主形式保存经过校验的递归分栏布局，读取兼容旧单轴分组；跨层拒绝重复功能、无效比例和过深布局，布局类型提供语义相等比较用于并发校验，兼容 JSON 整数与浮点比例；提供共享尺寸、置顶持久化、统一 Dev 设置入口和锚点请求，不管理任务或模型业务。

[PROTOCOL]: 职责或接口变化时更新本文，并检查父级地图。

features.rs负责主界面接管后的缺失成员补登记，只补开关已开启且无条目的outline/next/board；旧桌面/旧看板窗口存在、整组交接中或当前系统不支持目标形式时暂不迁移。已有条目的owner/open/布局不改。task_command复用原任务服务，打开看板与功能开关统一接入这一策略。

terms 使用同一主窗口与功能owner，业务读取/操作转 terminology，locate 沿用 owner 与交接互斥校验；有私有词库时为已管理主界面补登记，不重开已关闭条目。
