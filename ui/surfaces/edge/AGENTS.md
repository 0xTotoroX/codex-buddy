# ui/surfaces/edge/ — 贴边窗口

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `main.ts`：共享贴边标签、稳定视口内的功能挂载、原生几何/scene-ready 确认、悬停及退出生命周期；收起和换标签保留挂载与草稿；观察活动视图的自然尺寸并上报宽高，收放动画期间延后测量。
- `styles.css`：最小标签壳及展开布局，不参与原生轮廓缩放。

每个功能拥有独立的顶栏操作位置，随标签显隐与 owner 一起回收；按钮操作仍由功能视图提供。

收起入口不绘制圆点，展开头部保留功能标签、当前功能提供的操作；不显示手动收起按钮，保留 Esc。悬停约 450ms 后收起，编辑、按住或业务操作期间保持展开；原生遮罩、跨屏幕和全屏空间由既有后台窗口管理。主题与显示器/边缘/位置由设置页管理，不进入功能模块。
