# ui/surfaces/workspace/ — 共用工作台容器

> L2 | 父级：[AGENTS.md](../AGENTS.md)

侧栏、页面浮层和桌面窗口共用头部、标签、分栏、分隔线和临时放大。布局操作保留已有功能节点，不修改任务或模型数据；按承载形式保存布局，草稿和阅读位置通过功能会话交接。

- `chrome.js`：原工作台头部、84×36 表情、桌面置顶图标模板；不绘制设置入口。
- `layout.js`：通用功能标签、拖动分栏/合并、比例及临时放大；切换承载时清空旧分栏节点，只操作容器直属分隔线；标签同行展示活动功能的操作槽，分栏和切换时保持对应关系；与设置页共用 resolveFeatureLayout 读取新旧布局，保存携带已确认布局快照，冲突后恢复远端布局并保留挂载。
- `arrangement.js`：标题/标签拖动、落位预览、键盘标签导航和专注查看；通过 composedPath 接入 Shadow DOM 内标题，取消不触发业务或窗口拖动。
- `separator.js`：新旧工作台共用的指针/键盘分隔线调节。
- `mount.tsx`：共用 Shadow DOM/React 挂载与样式隔离；提供 mountFeature 和兼容 mountBoard；大纲/下一步/看板提供稳定的顶部操作槽，卸载时一并回收；透传可选的 `headerActions` 位置，供功能将自己的按钮放入容器顶栏；开发重载前冻结输入并保存草稿，繁忙/交接/拖动时延期。
- `feature-session.tsx`：owner 校验、读取、繁忙/错误状态、草稿及阅读交接生命周期，共用 shared/scroll 保留隐藏或尺寸夹紧前的阅读位置；将内容委托 features/content，不解析 Codex DOM。
- `content.css`：隔离挂载的容器尺寸、通用状态和标题样式；隔离视图的刷新按钮继承容器悬停状态，键盘聚焦及触屏仍显示；内容规则由 features 提供，材质配方由 theme 提供。
- `styles.css`：头部、窗内布局、标签和分隔线；操作与刷新随整个工作台悬停显现，键盘和触屏仍可用。
- `reading.js`：转用 shared/scroll 的旧窗口协议临时阅读记录，按聊天/内容身份恢复，保留隐藏标签被浏览器夹紧前的滚动意图。
- `legacy.js`：旧双面板工作台增量渲染与 DOM 接续，复用公共头部、编排、分隔线和功能内容。
- `legacy-layout.js`：旧双面板的尺寸约束、自动方向决策和比例迁移，保留旧设置契约。
- `legacy-features.js`：旧试点配置的大纲/看板选择、挂载与回收，使用同一个 Board 及共用隔离挂载。
- `legacy-content.js`：将旧 runtime 状态适配成 features/outline 和 features/next 所需投影及回调，不保留第二份完整内容实现。

公共表情保持居中、两侧等宽。展开态只显示眼睛，桌面另有默认开启且可保存取消的置顶按钮；单击按保存偏好收放，双击或 Alt+Enter 往返桌面，桌面单击不收起。设置仅从宿主左侧图标右键打开；来源文字及布局菜单保持隐藏，个性化布局放设置页。标签只用文字明暗表达选中，不加下划线，保留键盘焦点。

拖动标题或标签到边缘分栏、中央合并，分隔线调节比例；双击标题临时放大，Esc 恢复，标题支持 Enter/空格。临时放大不写入持久化配置；有效松手才保存编排，取消不修改布局。布局缩窄不通过卸载隐藏功能丢失草稿。

旧双面板路径仍用于未迁移的 panel 配置、旧窗口投影与 CLI。旧比例、group/active/mode/first 和两轴比例仍可读取，停靠与浮窗独立；业务内容已统一。只有这些入口迁移完成、旧租约失效、配置和阅读恢复可由通用路径接续后，才移除 legacy* 和 reading.js 的旧协议部分。
