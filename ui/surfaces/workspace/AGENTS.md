# ui/surfaces/workspace/ — 共用工作台容器

> L2 | 父级：[AGENTS.md](../AGENTS.md)

侧栏、页面浮层和桌面窗口共用头部、标签、分栏、分隔线和临时放大。布局操作保留已有功能节点，不修改任务或模型数据；按承载形式保存布局，草稿和阅读位置通过功能会话交接。

- `chrome.js`：共用头部、桌面窗口控件及置顶占位；头部不绘制设置齿轮；设置统一从独立眼睛快捷菜单进入。
- `layout.js`：通用功能标签、递归分栏/合并、各层比例及临时放大；切换承载时清空旧分栏节点，只操作容器直属分隔线；标签同行展示活动功能的操作槽，分栏和切换时保持对应关系；与设置页共用 resolveFeatureLayout 读取新旧布局，保存携带已确认布局快照，冲突后恢复远端布局并保留挂载。
- `layout-tree.js`：递归布局的叶子遍历、最小尺寸和局部拆分/合并；空栏配额在本层交给相邻目标或可见保留区域后再移除，嵌套压缩保留父级权重；隐藏功能保留偏好，设置页复用叶子顺序。
- `arrangement.js`：标题/标签拖动、落位预览、键盘标签导航和专注查看；通过 composedPath 接入 Shadow DOM 内标题，取消不触发业务或窗口拖动。
- `separator.js`：elementScale 读取页面缩放，新旧工作台共用指针/键盘调节；read 返回可选 scale 时，将鼠标屏幕位移换成 CSS 位移，键盘保持 CSS 步长；未提供 scale 的既有屏幕尺寸调用保持兼容。
- `mount.tsx`：共用 Shadow DOM/React 挂载与样式隔离；提供 mountFeature 和兼容 mountBoard；大纲/下一步/看板/模型提供稳定的顶部操作槽，卸载时一并回收；透传可选的 `headerActions` 位置，供功能将自己的按钮放入容器顶栏；为贴边测量自然内容尺寸，有 intrinsic 标记的模型内容宽度上限为976px（另加贴边外壳内距），其他内容保留原上限；列宽拖动期间暂停测量，松手后按实际换行适配高度；测量后恢复阅读位置；开发重载前冻结输入并保存草稿，繁忙/交接/拖动时延期。
- `feature-session.tsx`：owner 校验、读取、繁忙/错误状态、草稿及阅读交接生命周期，收到 closing 时捕获草稿/阅读状态并发送 disable-ready，后台确认后再回收原生窗口；卸载前补存当前视图，共用 shared/scroll 保留隐藏或尺寸夹紧前的阅读位置；将内容委托 features/content，按功能应用保存字号或默认值，旧配置沿用大纲/下一步字号偏移，不解析 Codex DOM。
- `content.css`：隔离挂载的容器尺寸、通用状态和标题样式；普通隔离视图的刷新按钮继承容器悬停状态；模型刷新在“所有”目录内保持可见，名称行不再显示管理箭头；模型内容区取消顶部12px内距，让表头和模型紧接容器标题；使用可收缩的纵向容器，将滚动交给功能内整体常用区（仅承载空间不足时）/其他模型目录；贴边常用区按自然内容增高，不单独压缩矩阵；内容规则由 features 提供，材质配方由 theme 提供。
- `styles.css`：头部、窗内布局、标签和分隔线；操作与刷新随整个工作台悬停显现，键盘和触屏仍可用。
- `reading.js`：转用 shared/scroll 的旧窗口协议临时阅读记录，按聊天/内容身份恢复，保留隐藏标签被浏览器夹紧前的滚动意图。
- `legacy.js`：旧双面板工作台增量渲染与 DOM 接续，复用公共头部、编排、分隔线和功能内容。
- `legacy-layout.js`：旧双面板的尺寸约束、自动方向决策和比例迁移，保留旧设置契约。
- `legacy-features.js`：旧试点配置的大纲/看板选择、挂载与回收，使用同一个 Board 及共用隔离挂载。
- `legacy-content.js`：将旧 runtime 状态适配成 features/outline 和 features/next 所需投影及回调，不保留第二份完整内容实现。

侧栏工作台不显示顶部胶囊表情，保留16px空白；桌面44px拖动条右侧放置横线收回聊天、放大/还原及置顶，表情仅在独立入口。隐藏的旧 face 按钮仅兼容现有绑定和状态更新，不绘制图形、不接受焦点；桌面 Alt+Enter 和独立入口内/外动作继续往返。设置从独立眼睛快捷菜单打开；来源文字及布局菜单保持隐藏，个性化布局放设置页。标签只用文字明暗表达选中，不加下划线，保留键盘焦点。

拖动标题或标签到目标区域边缘二等分、中央合并；区域内可继续沿另一方向拆分，每层分隔线独立调节比例。窄窗仅临时调整呈现方向，不改保存结构；双击标题临时放大，Esc 恢复，标题支持 Enter/空格。临时放大不写入持久化配置；有效松手才保存编排，取消不修改布局。布局缩窄不通过卸载隐藏功能丢失草稿。

落位预览按实际定位父级的缩放、边框及滚动换算；分栏尺寸与最小值统一使用 CSS 像素。局部拆分检查目标实际空间，同轴相邻独立栏移动可共用两栏空间，不能仅凭整窗足够就挤动其他栏。合并不保留空占位，也不把其他栏重新等分；分隔线回收仍可能产生少量像素变化。

来源移走最后一个可见标签后，即使分组还留有关闭功能，也转移释放的可见配额；隐藏分组保留历史身份和权重。重新开启隐藏分组时，它作为新的可见区域参与空间分配。

旧双面板路径仍用于未迁移的 panel 配置、旧窗口投影与 CLI。旧比例、group/active/mode/first 和两轴比例仍可读取，停靠与浮窗独立；业务内容已统一。只有这些入口迁移完成、旧租约失效、配置和阅读恢复可由通用路径接续后，才移除 legacy* 和 reading.js 的旧协议部分。

`window-controls.js` 处理横线收回与放大/还原操作和原生状态确认；hide保留页面/租约，toggle-maximize保存普通几何，window-state回读状态。geometryTransient阻止临时几何写入持久偏好。窗口操作与置顶共用18px图形、28px按钮和工作台悬停显现规则。

共享容器支持第五项 terms，通过 features/content 委托术语积木视图，继续使用同一布局/交接机制。

feature-session 使用共享 typography 快照与偏好，并补偿包含 Shadow DOM 在内的祖先 CSS zoom；无新协议时保留旧 per-feature 回退。各功能正文统一字号，标题/辅助文字保留比例，固定18px图标与窗口尺寸不随字号机械放大。
