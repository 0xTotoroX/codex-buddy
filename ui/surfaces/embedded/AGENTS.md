# ui/surfaces/embedded/ — 嵌入 Codex

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `dock.js`：识别主聊天、新版标签页与独立聊天，按最近操作的聊天上下文创建可撤销侧栏占位；收起释放占位，空间不足或不支持时只保留左栏入口，不显示说明或替代菜单，保留位置和宽度偏好。dockWidthLimit 排除文件侧栏，为拖动返回当前可用上限；按实际空间临时缩窄，不覆盖保存宽度；销毁后拒绝迟到回调与挂载。
- `width.js`：新旧侧栏共用的调宽手势与最小宽度；拖至收起断点时恢复拖动前保存宽度并关闭，键盘调宽止于最小宽度。
- `features.js`：将全部非贴边功能挂到共用内容区，接入 workspace/layout 分栏及侧栏调宽；mainPlacement 选择侧栏或浮层，切换承载时取消未完成的收放，浮层释放占位，桌面接管后隐藏宿主主界面，返回时恢复出发前的开合状态。
- `launcher.js`：默认挂载独立眼睛入口，与插件是否存在无关；单击收放、双击/Alt+Enter 保持窗口往返，右键及 Option+右键统一打开内置浏览器设置。官方按钮复用仅在显式 reuseOfficial=true 时启用，旧插件页签试验与设置适配代码保留但产品入口不调用；导航重建恢复唯一自有图标，停止时清理节点和监听。入口不绘制分隔线，抵消与头像之间的导航间距，使用36×28px紧凑按钮，眼睛在悬停底色与点击区内居中，头像原位、点击区互不重叠；菜单向上展开时两者位置不变。
- `legacy.js`：旧 panel 配置的停靠生命周期与宽度/阅读保存，供仍可达的兼容工作台使用。
- [shell/AGENTS.md](shell/AGENTS.md)：共用外壳、几何、表情、页面浮层曲面收放和键盘操作，保留胶囊兼容代码。

Codex 容器识别由 ui/codex/page-context.js 提供，输入与内容读取留在 codex。嵌入层不把自有功能节点识别为聊天。所有新功能位置完成迁移、旧 panel 入口退出后，才能删除 legacy.js。

布局保存将 workspace 持有的 expectedLayout 交给后台，避免覆盖设置页刚保存的编排；失败后由共用布局模块重新接收远端布局，功能草稿不卸载。

[PROTOCOL]: 结构、职责或接口变化时更新本文；父级描述受影响时同步父级地图。

features.js 首次接管遵循后台 mainManaged；只有模型贴边时保留 legacy 工作台。旧后台缺少此字段时兼容原逻辑，已接管的页面不因最后一项移到贴边而恢复旧内容。

官方按钮识别优先 aria-label 与正文，再兼容 title；设置打开状态仅放 data-buddy-settings-status，不改写宿主标题，避免失去匹配后重复注入备用入口。

Option+右键仅在当前聊天入口可用且已提供 settingsBrowser 回调时拦截；普通右键不拦截。兼容眼睛入口共用快捷动作，停止时清除官方 contextmenu 监听。

- `launcher-menu.js`：独立眼睛的栏内快捷菜单，内/外/设置竖排；节点放在眼睛同一 Shadow DOM 内并参与侧栏布局，不使用 body portal 或 fixed 定位。110ms 悬停打开、180ms 离开缓冲，220ms 高度伸缩配合按钮错峰显现；菜单居中位于眼睛上方，栏内自动让位，按钮仍44×50；键盘/Esc、inert、减少动态效果、动作单飞及销毁清理沿用。默认单击动作来自后台 launcherAction。

菜单不再绘制独立背景、玻璃、边框或阴影，直接沿用宿主侧栏底色；保留按钮 hover、按下、焦点反馈与栏内伸缩动画。其他容器的材质偏好不受影响。

- `launcher-face.js`：独立眼睛复用 statusStageHtml 与共享 faceStyles；只接收 runtime 派生表情及 activePaneCue，36×28px按钮内适配原表情，合法多聊天来源以边缘小点标记并沿按钮边缘的椭圆轨迹平滑移动。保留按钮/菜单节点与事件，不读取正文或重选聊天；隐藏/模糊/销毁清理视线和动画帧。

features.updateDock仅统计open或pending的功能；已关闭条目只保留配置，不占侧栏空间，也不因单击入口自动重开。

内／外／设置三个菜单动作开始时，launcher 触发 launcher-face 的280ms轻眨/抬眼反馈；独立于运行时表情，不等待动作完成或表示成功。连续触发取消上一段，业务刷新保留反馈；减少动态效果使用140ms静态明暗反馈，隐藏/销毁/偏好变化清理动画。
