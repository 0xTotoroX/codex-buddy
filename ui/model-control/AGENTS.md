# ui/model-control/ — 独立模型控制条

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

入口与工作台完全独立。宿主适配器通过 CDP 安装，原生 NSPanel 加载单一网页视图；只通过受鉴权的 model-control API 协作，不导入建议生成模块或工作台业务状态。跟随唯一输入目标，不能继承大纲阅读锁定。外观只读跟随现有材质、Regular/Clear 与字号；复用 ui/tokens.css 和原生共享背景，不维护独立绿色配色或另一套玻璃效果。

- `host.js`：观察关联的官方 model/list 能力，识别稳定聊天目标，经官方菜单执行并回读；生成中、旧目标、冲突或能力未知时拒绝切换；有界事务可取消，部分完成明确报告。
- `index.html`：紧凑入口和唯一展开面板的语义结构，不包含用户数据。
- `app.js`：单一交互状态、授权请求、悬停与键盘焦点、预设管理、排序、列宽及原生 IPC；期望值不替代实际回读。
- `view.js`：共享图标、配置验证、文本描述及保留节点身份的列表协调；复用公开 OpenAI 图标模块。
- `styles.css`：紧凑/展开、边缘/顶部、明暗主题、统一尺寸和对齐、响应式矩阵及减少动态效果。
- `LICENSE.model-deck`：宿主适配器所参考 Model Deck 的 MIT 许可原文，分发收集署名。

[PROTOCOL]: 结构或协议变化时更新本文，并检查父级地图；私人验收记录不进入公开资源。
