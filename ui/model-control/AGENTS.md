# ui/model-control/ — 独立模型控制条

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

入口与工作台完全独立。宿主适配器通过 CDP 安装，原生 NSPanel 加载单一网页视图；只通过受鉴权的 model-control API 协作，不导入建议生成模块或工作台业务状态。跟随唯一输入目标，不能继承大纲阅读锁定。默认独立纯黑凹角外壳，可选哑光、原生磨砂、液态；纯黑始终保持固定深色配色，其他三种材质所有状态只读继承宿主明暗与语义色；所有材质继承宿主字号并共用图标，不改变工作台材质。收起入口与展开面板共用所选材质；液态使用中性可读性衬色，保持网页文字对比。默认预设栏、共用表头矩阵与单行来源，搜索/详情按需显示，矩阵过宽则横向滚动。

- `host.js`：观察关联的官方 model/list 能力，优先识别输入区/祖先的稳定聊天身份，引用注释仅作为无权威身份时的回退；提供宿主可见性/焦点，经官方菜单执行并回读；支持独立子菜单、内联选项、simple/advanced同根视图、显式模型后的推理滑块及Fast复选项/速度飞出菜单；从菜单内读取模型名、从可访问标签读取速度，关闭后记录稳定缓存，已选高级项可返回简洁视图；显式操作附有界无正文阶段诊断；先记录菜单归属再解析，失败清理自身菜单；旧目标、冲突、官方控件禁用或能力未知时拒绝切换；生成状态不单独阻塞；有界事务可取消，部分完成明确报告。
- `index.html`：紧凑入口和展开内容共用常驻无内边距外壳的语义结构，不包含用户数据。
- `app.js`：单一交互状态、授权请求、原生鼠标边界事件优先的悬停状态、内容高度IPC与键盘焦点、独立材质、宿主配色、显示器/位置设置、预设管理、排序、列宽及原生 IPC；首次模型点击在一次apply事务内同步实际配置、保留可用Fast并应用，不单独刷新；同根菜单只打开一次、只改变化项、最终关闭核验；期望值不替代实际回读。
- `view.js`：共享图标、配置验证、文本描述及保留节点身份的列表协调；复用公开 OpenAI 图标模块。
- `styles.css`：紧凑/展开、边缘/顶部、固定纯黑外壳及跟随宿主配色的三材质前景、统一尺寸和对齐、可滚动矩阵及减少动态效果；外壳和内容跟随原生统一展开进度；外壳可连续收至10pt，内容在动画期间保持目标宽度，不逐帧测量回传；稳定后恢复响应式尺寸。
- `LICENSE.model-deck`：宿主适配器所参考 Model Deck 的 MIT 许可原文，分发收集署名。
