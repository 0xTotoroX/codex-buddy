# ui/model-control/ — 模型宿主适配器

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

模型业务适配与呈现解耦。功能内容由 ui/features/model.tsx 提供，所有形式复用；旧专用页面已移除，/model-control 兼容入口转到设置页。

- `host.js`：观察关联的官方 model/list 能力，优先识别输入区/祖先的稳定聊天身份，引用注释仅作为无权威身份时的回退；提供宿主可见性/焦点，经官方菜单执行并回读；支持独立子菜单、内联选项、simple/advanced同根视图、显式模型后的推理滑块及Fast复选项/速度飞出菜单；从菜单内读取模型名、从可访问标签读取速度，关闭后记录稳定缓存，已选高级项可返回简洁视图；显式操作附有界无正文阶段诊断；先记录菜单归属再解析，失败清理自身菜单；旧目标、冲突、官方控件禁用或能力未知时拒绝切换；生成状态不单独阻塞；有界事务可取消，部分完成明确报告。
- `LICENSE.model-deck`：宿主适配器所参考 Model Deck 的 MIT 许可，分发保留署名。
