# ui/model-control/ — 独立模型控制条

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

入口与工作台完全独立。宿主适配器通过 CDP 安装，原生 NSPanel 加载单一网页视图；只通过受鉴权的 model-control API 协作，不导入建议生成模块或工作台业务状态。跟随唯一输入目标，不能继承大纲阅读锁定。默认独立不透明纯黑凹角外壳，可选哑光、原生磨砂、液态；只读继承字号并共用图标，不改变工作台材质。液态使用中性可读性衬色，保持网页文字对比。默认预设栏、共用表头矩阵与单行来源，搜索/详情按需显示，矩阵过宽则横向滚动。

- `host.js`：观察关联的官方 model/list 能力，优先识别输入区/祖先的稳定聊天身份，引用注释仅作为无权威身份时的回退；提供宿主可见性/焦点，经官方菜单执行并回读；支持独立子菜单、内联选项、simple/advanced同根视图、显式模型后的推理滑块及Fast复选项；先记录菜单归属再解析，失败清理自身菜单；生成中、旧目标、冲突或能力未知时拒绝切换；有界事务可取消，部分完成明确报告。
- `index.html`：紧凑入口和唯一展开面板的语义结构，不包含用户数据。
- `app.js`：单一交互状态、授权请求、原生鼠标边界事件优先的悬停状态、内容高度IPC与键盘焦点、独立主题、显示器/位置设置、预设管理、排序、列宽及原生 IPC；首次模型点击先同步实际配置再应用，不要求额外手动刷新；期望值不替代实际回读。
- `view.js`：共享图标、配置验证、文本描述及保留节点身份的列表协调；复用公开 OpenAI 图标模块。
- `styles.css`：紧凑/展开、边缘/顶部、默认黑色及三材质前景、统一尺寸和对齐、可滚动矩阵及减少动态效果。
- `LICENSE.model-deck`：宿主适配器所参考 Model Deck 的 MIT 许可原文，分发收集署名。
