# ui/features/ — 固定功能视图

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

大纲、下一步、看板、模型快切只消费既有业务投影和受限命令。宿主与桌面挂载同一视图，不启动额外生成或同步循环；Shadow DOM 隔离宿主样式。每功能一个活动 owner；来源冻结并保存临时状态，目标准备就绪后接管。

- `types.ts`：固定功能名称、位置、归属与临时阅读契约。
- `mount.tsx`：Shadow DOM/React 挂载、目标 ready 与销毁。
- `view.tsx`：功能壳、位置/关闭操作、大纲/建议投影、身份校验命令、草稿确认与内存阅读交接。
- `model.tsx`：按服务能力显示模型/推理/速度、置顶和预设；只显示实际回读配置。
- `styles.css`：克制的明暗样式及窄宽度控制布局。
- `main.ts`：独立 Wry 页面的认证请求、归属轮询及页面生命周期。

[PROTOCOL]: 变更时更新本文，然后检查父级 AGENTS.md。
