# ui/features/model/ — 模型快切内容

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `view.tsx`：保留圆点推理矩阵和常用模型排序；标题操作槽显示目录图标，没有操作槽时使用内容顶栏。“所有”在原面板内容区按厂家/手动组直接展示全部模型积木，包含已常用项；点击串行保存加入/移出，保持目录与实际模型选择，失败不伪造选中状态。刷新位于目录关闭按钮左侧。Fast 与收藏图标并排位于矩阵表头左侧；收藏图标复用原保存预设操作。底部低对比内嵌框放置收藏预设并自动换行，框内更多图标打开原模型工具；保留新增、改名、删除、失败草稿与配置捕获。
- `catalog.ts`：快切及设置共用的纯分类规则和类型；手动分组优先于手动厂家，再回退系列自动识别与未分类；路由前缀不代表厂家，同名不同ID仍为独立模型。
- `styles.css`：模型矩阵、表头握柄、原位切换目录、表头图标操作行和内嵌框中自然换行的收藏；使用容器语义颜色适配明暗与黑色主题，不绘制外层材质。积木仅以中性背景区分常用状态，没有对勾、图钉、计数或强调色。

顺序复用后台 modelOrder；只更新当前操作的偏好，保留旧常用、收藏、自定义组、手动厂家和暂不可用模型记录。expandedGroups仍兼容保存，快切不再依赖组内折叠状态。分组管理继续在Web设置“功能与交互 → 模型快切 → 模型分组”，不在快切增加分类编辑入口。

名称列保留100–560px偏好；实际宽度按视口扣除常用模型实际支持的思考标题宽度夹紧（未常用模型的独有档位不占列），临时夹紧不覆盖偏好。表头握柄位于名称列末端内侧，与思考列保持16px间距；支持指针按缩放换算、左右键微调、Esc取消、松手保存。无贯穿模型行的竖线、无水平分隔线、拖动无蓝色焦点框。贴边宽度仍由独立标记及420px名称预算决定，高度按实际名称列宽与换行测量，完整容纳常用模型和预设。拖动期间暂停原生尺寸测量，松手后再适配高度，宽度及贴边锚点保持。仅超过屏幕可用高度或在受限主界面中时，整个常用内容区滚动，不将矩阵单独压成滚动框。

目录图标由headerActions放到容器标题行，18px 图形、28px 点击区，无可见文字与下拉箭头，aria-label 保留“所有模型”。打开后目录占用同一内容区，矩阵/收藏保持挂载但隐藏并设inert，关闭后恢复原阅读位置；目录无第二层背景、边框或阴影。记录打开前内容高度供贴边自然测量使用，浏览/整理期间保持外框稳定。错误状态位于切换内容之外，两种模式均可见。目录列表独立滚动，关闭按钮、Esc、外部点击关闭；刷新使用原动作与禁用约束，操作完成以实际回读为准。

收藏区复用原presets；不显示“收藏”文字，空收藏且没有编辑草稿时隐藏内嵌框；框内更多图标复用原“模型工具”改名/删除入口，无预设时禁用。Fast 和保存收藏图标固定在表头左侧，不随列宽拖动位移。下方内嵌框中的快捷按钮整体换行，不限制三行或另设预设滚动条。新增捕获点击收藏图标时的完整模型/强度/速度，输入框不使用原生JavaScript prompt；支持Enter保存、Esc取消和IME组合保护，保存失败保留草稿。新增/改名草稿的 ID、名称、捕获的选择及 creating 在事件中同步写入 Reading.modelPresetDraft；清空也同步删除，不依赖被动 effect，卸载/owner 交接后恢复原选择而非当前模型。工具状态和横向阅读位置仍随临时状态交接。

既有名称中的“ · ”来源后缀在矩阵中分行弱化；重名模型在积木中保留完整ID以区分。能力与官方菜单匹配仍在ui/codex/model.js，身份校验/串行操作/持久化仍在src/model_control.rs；窗口与原生几何由surfaces负责。

内置系列规则覆盖OpenAI、Anthropic、Google、DeepSeek、阿里云、智谱、月之暗面、xAI、MiniMax、阶跃星辰、腾讯、Meta、Mistral、百度、字节跳动、小米、Amazon、Cohere、Microsoft和NVIDIA；不枚举模型能力，未接入厂家不生成空组。
