# ui/features/model/ — 模型快切内容

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `view.tsx`：原紧凑推理矩阵、常用模型直接显示、其他模型折叠，上下箭头直接移入移出、组内拖动排序、列宽、Fast 与预设；显示实际回读状态，通过注入操作提交选择。工具/其他模型展开状态和横向阅读位置随临时状态交接。
- `styles.css`：模型矩阵与控件布局，内容继承独立字号（默认 14px），列宽随字号扩展以避免表头重叠；使用容器提供的语义颜色，不绘制外层窗口或材质。

顺序使用后台 `modelOrder` 保存；旧配置按已有常用顺序和宿主模型顺序展示，不丢弃暂不可用模型的配置。

不提供模型搜索或列宽滑块；名称列右侧竖线支持拖动调宽、方向键微调和 Esc 取消，松手沿用 `modelColumnWidth` 保存。模型上下箭头跟随容器刷新按钮的悬停显隐，键盘聚焦与触屏仍可见；没有预设时不显示空的模型工具入口。

贴边窗口通过 `headerActions` 提供设置左侧的刷新位置，按钮使用 React Portal，操作和禁用状态仍由模型功能管理；其他形式保留工具行刷新。保存预设的加号始终位于工具行最右侧，“其他模型”与模型名称左对齐。

官方能力和菜单适配在 ui/codex/model.js，串行校验与预设保存保留在 src/model_control.rs；屏幕、边缘、悬停与原生轮廓属于 surfaces/edge。
