# ui/features/model/ — 模型快切内容

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `view.tsx`：保留圆点推理矩阵和常用模型排序；标题操作槽显示“所有”，没有操作槽时使用内容顶栏。弹层按厂家/手动组直接展示全部模型积木，包含已常用项；点击串行保存加入/移出，保持弹层与实际模型选择，失败不伪造选中状态。刷新与“所有”并排，右上角悬停或聚焦时显示。采用Opus最终版：Fast文字按钮位于名称列表头右端，独立握柄占用中间28px空间，两侧各6px留白。收藏预设及仅图标的加号放到底部；保留新增、改名、删除、失败草稿与配置捕获。
- `catalog.ts`：快切及设置共用的纯分类规则和类型；手动分组优先于手动厂家，再回退系列自动识别与未分类；路由前缀不代表厂家，同名不同ID仍为独立模型。
- `styles.css`：模型矩阵、表头握柄、受限弹层和最多三行的收藏换行；使用容器语义颜色适配明暗与黑色主题，不绘制外层材质。积木仅以中性背景区分常用状态，没有对勾、图钉、计数或强调色。

顺序复用后台 modelOrder；只更新当前操作的偏好，保留旧常用、收藏、自定义组、手动厂家和暂不可用模型记录。expandedGroups仍兼容保存，快切不再依赖组内折叠状态。分组管理继续在Web设置“功能与交互 → 模型快切 → 模型分组”，不在快切增加分类编辑入口。

名称列保留100–560px偏好；实际宽度按视口扣除实测思考标题宽度夹紧，临时夹紧不覆盖偏好。表头握柄支持指针按缩放换算、左右键微调、Esc取消、松手保存。无贯穿模型行的竖线、无水平分隔线、拖动无蓝色焦点框。贴边自然尺寸按独立标记及固定280px名称预算测量，拖动不改变外框；长名称换行时矩阵内部滚动，Fast随名称列右边界对齐。

“所有”由headerActions放到容器标题行，关闭时不占正文高度。弹层限定在功能视口内，短视口可贴到内容顶部；列表独立滚动，再次点击“所有”、Esc、外部点击关闭。打开弹层不改变贴边自然尺寸，选择与刷新保持当前弹层。刷新使用原动作与禁用约束，操作完成以实际回读为准。

“收藏”区复用原presets；快捷按钮整体换行，最多三行后内部滚动，加号只绘图标。预设编辑在底部锚定浮层中进行。原“模型工具”入口在收藏标题悬停/键盘聚焦时显示，保留改名与删除。新增捕获点击加号时的完整模型/强度/速度，输入框不使用原生JavaScript prompt；支持Enter保存、Esc取消和IME组合保护，保存失败保留草稿。工具状态和横向阅读位置仍随临时状态交接。

既有名称中的“ · ”来源后缀在矩阵中分行弱化；重名模型在积木中保留完整ID以区分。能力与官方菜单匹配仍在ui/codex/model.js，身份校验/串行操作/持久化仍在src/model_control.rs；窗口与原生几何由surfaces负责。

内置系列规则覆盖OpenAI、Anthropic、Google、DeepSeek、阿里云、智谱、月之暗面、xAI、MiniMax、阶跃星辰、腾讯、Meta、Mistral、百度、字节跳动、小米、Amazon、Cohere、Microsoft和NVIDIA；不枚举模型能力，未接入厂家不生成空组。
