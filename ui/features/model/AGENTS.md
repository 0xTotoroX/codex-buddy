# ui/features/model/ — 模型快切内容

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `view.tsx`：保留圆点推理矩阵和常用模型排序；目录入口固定在预设栏末尾添加图标右侧，不占用标题操作槽或增加内容顶栏。“所有”在原面板内容区按厂家/手动组直接展示全部模型积木，包含已常用项；点击串行保存加入/移出，保持目录与实际模型选择，失败不伪造选中状态。刷新位于目录关闭按钮左侧。闪电单击开启 Fast 时先充电，再向下放电，最后按实际状态显示实心；关闭时显示空心，下方细分隔线独立拖动调整名称宽度；底部仅保留独立内凹预设标签，末尾铅笔切换统一编辑模式，书签图标直接以模型名保存单个预设，无需确认；保留新增、改名、删除、失败草稿与配置捕获。
- `heading.tsx`：复用容器现有标题操作槽，将 Fast 与思考强度放到标题同行；按矩阵实际几何、字体、主题及横向滚动对齐，目录打开时隐藏当前“模型快切”标题入口，将当前分组名放在同一行左侧，右侧保留刷新/关闭按钮，卸载恢复标题布局；无操作槽的独立挂载保留本地表头。
- `fast-motion.ts`：接收正在执行的操作结果，只管理充电、保持充满、放电视觉时序和取消，不改变模型状态或发起保存。
- `catalog.ts`：快切及设置共用的纯分类规则和类型；uniquePresetName/uniquePresetNames 为预设名称补序号，保留ID、完整选择与显式已有编号，遵守256字节名称上限；手动分组优先于手动厂家，再回退系列自动识别与未分类；路由前缀不代表厂家，同名不同ID仍为独立模型。
- `styles.css`：模型矩阵、Fast按钮、独立分隔线与电流动效、原位切换目录、自然换行的内凹标签及编辑删除控件；使用容器语义颜色适配明暗与黑色主题，不绘制外层材质。积木仅以中性背景区分常用状态，没有对勾、图钉、计数或强调色。

顺序复用后台 modelOrder；只更新当前操作的偏好，保留旧常用、收藏、自定义组、手动厂家和暂不可用模型记录。expandedGroups仍兼容保存，快切不再依赖组内折叠状态。分组管理继续在Web设置“功能与交互 → 模型快切 → 模型分组”，不在快切增加分类编辑入口。

名称列保留100–560px偏好；实际宽度按视口扣除常用模型实际支持的思考标题宽度夹紧（未常用模型的独有档位不占列），临时夹紧不覆盖偏好。容器标题、闪电与思考强度位于同一行，内容不再额外占一行表头；闪电与名称/思考之间16px间隙的中轴对齐；分隔线从闪电下方延伸到最后一行模型，16px透明拖动区支持指针按缩放换算、左右键微调、Esc取消、松手保存。闪电只切换Fast，禁用遵守目标与能力状态；开启时360ms自下向上填充充电；充满后先固化实心填充，保持至切换结果确认，再接续340ms SVG电流（145ms向下揭示），结束后仅在实际回读为Fast时保留实心；关闭立即恢复空心。动画与串行业务请求同时开始，失败、打开目录、拖动或卸载取消动画；减少动态效果直接显示实际状态，无充电或电流。动画清理时底层填充直接跟随真实状态，不依赖phase更新，防止收尾空心闪帧。四个图标按钮（Fast、编辑、添加、目录）共用18px OpenAI图标和28px按钮盒。实心状态同时核对当前模型Fast能力与实际speed；标准或不支持Fast的模型保持空心。不支持Fast仍可调宽；拖动无蓝色焦点框，键盘聚焦通过细线加亮表示。无水平分隔线。贴边宽度仍由独立标记及420px名称预算决定，高度按实际名称列宽与换行测量，完整容纳常用模型和预设。拖动期间暂停原生尺寸测量，松手后再适配高度，宽度及贴边锚点保持。仅超过屏幕可用高度或在受限主界面中时，整个常用内容区滚动，不将矩阵单独压成滚动框。

目录图标在预设操作组内，按编辑、添加、目录排列，18px 图形、28px 点击区，无可见文字与下拉箭头，aria-label 保留“所有模型”。打开后刷新与关闭位于“模型快切”标题行右侧，目录不另设工具栏空行；列表与标题左边界对齐，常用与目录内容紧接标题行；额外12px留白只加在标题行上方。目录首组标题提升至容器顶行，首组积木紧接在下；滚动时顶行标题跟随到达列表顶部的分组。目录占用同一内容区，矩阵/收藏保持挂载但隐藏并设inert，关闭后恢复原阅读位置；目录无第二层背景、边框或阴影。记录打开前内容高度供贴边自然测量使用，浏览/整理期间保持外框稳定。错误状态位于切换内容之外，两种模式均可见。目录列表独立滚动，关闭按钮、Esc、外部点击关闭；刷新使用原动作与禁用约束，操作完成以实际回读为准。

收藏区复用原presets；无外层背景框，仅独立标签通过中性内阴影呈现凹槽。只有Fast预设带实心闪电，标准预设不占图标位。普通模式单击应用完整选择；末尾铅笔切换统一编辑模式，所有标签左上角出现28px删除叉号，此时点击标签只进入原位改名，不调用模型。再次点铅笔或Esc退出编辑。删除按钮与标签是独立兄弟控件，失败保留预设和草稿。末尾书签图标捕获当前完整模型/强度/速度，直接以模型名追加独立预设，不弹出命名或确认表单；失败显示错误且不伪造新标签；新增和改名按当前完整列表核对名称，重名补2、3等序号，允许同一模型及同一配置保存多份预设，不按模型ID去重；输入框不使用原生JavaScript prompt，支持Enter保存、Esc取消与IME保护。改名与兼容旧新增草稿的 ID、名称、选择和creating同步写入Reading.modelPresetDraft；清空也同步删除，卸载/owner交接后恢复原选择。编辑模式通过原Reading.modelTools交接。标签和操作随空间自然换行，不另设预设滚动条。

既有名称中的“ · ”来源后缀在矩阵中分行弱化；重名模型在积木中保留完整ID以区分。能力与官方菜单匹配仍在ui/codex/model.js，身份校验/串行操作/持久化仍在src/model_control.rs；窗口与原生几何由surfaces负责。

内置系列规则覆盖OpenAI、Anthropic、Google、DeepSeek、阿里云、智谱、月之暗面、xAI、MiniMax、阶跃星辰、腾讯、Meta、Mistral、百度、字节跳动、小米、Amazon、Cohere、Microsoft和NVIDIA；不枚举模型能力，未接入厂家不生成空组。
