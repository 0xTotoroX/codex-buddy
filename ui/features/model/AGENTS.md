# ui/features/model/ — 模型快切内容

> L2 | 父级：[AGENTS.md](../AGENTS.md)

- `view.tsx`：原紧凑推理矩阵、常用模型直接显示、其余模型整体收在默认关闭的“其他模型”选择区内，展开后按厂家或手动组折叠，上下箭头直接移入移出、组内拖动排序、列宽、Fast 与预设；显示实际回读状态，通过注入操作提交选择。刷新只在右上角操作区域悬停时显示，矩阵用独立的自然尺寸标记供贴边测量。工具状态和横向阅读位置随临时状态交接；分组开合通过 expandedGroups 持久保存。
- `catalog.ts`：快切及设置共用的纯分类规则和类型；按模型系列保守识别厂家，不把路由前缀当厂家；手动分组优先于手动厂家，再回退自动分类与未分类。同名不同 ID 保留独立能力和入口。
- `styles.css`：模型矩阵与控件布局，内容继承独立字号（默认 14px），推理列宽随字号扩展以避免表头重叠，长模型名称完整换行而不截断；使用容器提供的语义颜色，不绘制外层窗口或材质。

顺序使用后台 `modelOrder` 保存；旧配置按已有常用顺序和宿主模型顺序展示，不丢弃暂不可用模型的配置。

不提供模型搜索或列宽滑块；名称列宽保留100–560px的已有偏好；实际渲染和拖动上限按当前视口扣除逐列实测思考标题宽度，空间不足仅临时夹紧，不写回偏好，最窄空间保留横向滚动。右侧竖线只调整内部两列，外框固定；指针位移按 CSS 缩放换算，方向键微调、Esc 取消，松手沿用 `modelColumnWidth` 保存。贴边自然尺寸以固定280px名称预算测量宽高，与拖动值分离；名称变窄后的长内容在内部滚动。模型上下箭头仅随分割线左侧名称单元格或名称表头悬停显示，右侧思考强度区域不显现箭头，刷新仅随右上角操作区域悬停显示，键盘聚焦与触屏仍可见；没有预设时不显示空的模型工具入口。

贴边窗口通过 `headerActions` 提供设置左侧的刷新位置，按钮使用 React Portal，操作和禁用状态仍由模型功能管理；其他形式保留工具行刷新。保存预设的加号始终位于工具行最右侧，分组标题与模型名称左对齐。新增与改名在面板内按需显示名称输入行，不依赖原生 JavaScript 弹窗；新增捕获点击加号时的完整模型配置，保存失败保留输入，支持 Enter 保存及 Esc 取消。

官方能力和菜单适配在 ui/codex/model.js，串行校验与预设保存保留在 src/model_control.rs；屏幕、边缘、悬停与原生轮廓属于 surfaces/edge。

分类偏好复用 model-control.json：groups 为自定义组，modelOverrides 按完整模型 ID 保存厂家及归属，groupOrder 与 expandedGroups 保存组序和开合。常用仍独立置顶且不在组内重复。管理仅在 Web 详细设置的“功能与交互 → 模型快切 → 模型分组”，不在快切新增管理入口；暂不可用模型不删除已保存的顺序或分类。

内置厂家规则覆盖 OpenAI、Anthropic、Google、DeepSeek、阿里云、智谱、月之暗面、xAI、MiniMax、阶跃星辰、腾讯、Meta、Mistral、百度、字节跳动、小米、Amazon、Cohere、Microsoft 和 NVIDIA；按系列匹配，不枚举可用模型或推理能力，未接入厂家不生成空组。

常用与“其他模型”之间保留水平分隔线；选择区只保留当前挂载内的临时开合，重新挂载默认只显示常用，不受 expandedGroups 的组内偏好影响。加入常用保存成功后关闭选择区，失败保持展开；移出常用不自动展开选择区。分割线拖动不绘制焦点矩形，键盘聚焦以中性色细线提示。
