# ui/features/board/ — 独立任务看板

> L2 | 父级：[AGENTS.md](../AGENTS.md)

由通用功能容器或 ui/surfaces/desktop/legacy-board.tsx 挂载，复用注入任务客户端，不依赖设置视图或宿主聊天。默认待办、进行中、完成三组，名称修改和新增本地分组统一在设置页操作；默认卡片仅标题、组内创建，备注与键盘阶段选择在详情。旧归档记录在完成组保留，可从详情移回未完成；旧 waiting 显示为待办且不改原值。

- [api.ts](api.ts)：任务类型、字段格式与可注入认证客户端（默认客户端延迟导入，不读取宿主令牌）；本地编辑串行，旧响应不得覆盖新状态。
- [app.tsx](app.tsx)：与承载形式无关的动态分组、组内快速创建和底部按需搜索（入口在右下角，输入框同处底部，任务区独立滚动）；以 680px 容器宽度选择多列或同名标签，窄标签也是放置目标，接续编辑与快速创建草稿。
- [card.tsx](card.tsx)：标题卡片与列放置区，直接处理浏览器 drag/drop 事件以兼容 Shadow DOM；最近卡片接收排序，列/标签接收跨组移动，列内顺序只存本地。
- [editor.tsx](editor.tsx)：任务编辑、字段冲突对比、恢复及旧归档记录返回未完成；日常只编辑标题、备注、阶段，旧日期/优先级保留；失败保留编辑草稿，同一任务原快照变化拒绝覆盖，无关修订可刷新后重试。
- [styles.css](styles.css)：响应式多列、统一圆角与间距，卡片和操作 15px、状态至少 14px；独立页默认明暗主题及高对比、焦点和减少动态效果；嵌入工具栏透明，内容跟随承载材质。

[PROTOCOL]: 文件或职责变化时同步本文与父级地图。

BoardView 增加原任务快照、revision、草稿字段及暂停编辑状态；Editor 的“保留草稿并返回”允许迁移前退出模态层。locked 在交接时禁用真实输入（包括可逃逸祖先 inert 的 modal）；移动不保存任务，expectedTask 仍校验原快照。
