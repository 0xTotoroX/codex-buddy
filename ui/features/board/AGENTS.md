# ui/features/board/ — 独立任务看板

> L2 | 父级：[AGENTS.md](../AGENTS.md)

由通用功能容器或 ui/surfaces/desktop/legacy-board.tsx 挂载，复用注入任务客户端，不依赖设置视图或宿主聊天。默认待办、进行中、完成三组，名称修改和新增本地分组统一在设置页操作；默认卡片仅标题、组内创建，悬停或键盘聚焦显示垃圾桶，点击直接本地删除；触屏保持可见，不弹出任务详情。旧归档记录在完成组保留，可拖回未完成组；旧 waiting 显示为待办且不改原值。

- [api.ts](api.ts)：任务类型、字段格式与可注入认证客户端（默认客户端延迟导入，不读取宿主令牌）；本地编辑串行，旧响应不得覆盖新状态；显示开关已保存后的独立窗口错误，不回退任务修订。
- [app.tsx](app.tsx)：与承载形式无关的动态分组、组内快速创建和按需搜索（入口放入容器的功能标题操作槽，输入框在底部，任务区独立滚动；旧独立页回退底部入口）；以 680px 容器宽度选择多列或同名标签，窄标签也是放置目标，接续快速创建草稿。
- [card.tsx](card.tsx)：标题卡片、悬停删除与列放置区，直接处理浏览器 drag/drop 事件以兼容 Shadow DOM；最近卡片接收排序，列/标签接收跨组移动，列内顺序只存本地。
- [recovery.tsx](recovery.tsx)：仅冲突或远端缺失时显示行内处理入口，沿用原快照校验与恢复确认；普通任务无详情或编辑表单。
- [styles.css](styles.css)：响应式多列、统一圆角与间距，卡片和操作使用独立内容字号（默认 15px）、辅助状态至少 14px；独立页默认明暗主题及高对比、焦点和减少动态效果；嵌入工具栏透明，内容跟随承载材质。

[PROTOCOL]: 文件或职责变化时同步本文与父级地图。

BoardView 保存搜索、阶段、横向阅读位置及快速新建草稿；窗口交接保留草稿，locked 禁用任务操作。删除带 expectedTask 防止误删已更新的任务；后台只移除本地任务并记住远端身份，不删除 Apple 提醒事项。
