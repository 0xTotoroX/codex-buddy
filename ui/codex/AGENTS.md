# ui/codex/ — Codex 页面适配

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

读取和操作 Codex 页面，保留必须在浏览器环境执行的逻辑。context/composer 不依赖功能视图；outline/next 协調现有业务状态与受限后台请求，呈现交给 ui/features。

- `plugin-tab.js`：官方 Buddy 插件标签适配；右键设置显式 follow=false 只手动打开，原 Dev 自动跟随试验仍默认停用；身份复用 context 的主聊天标记识别，新版“新标签页”经 contextmenu 打开插件菜单而非创建浏览器页，错误带阶段；兼容统一任务标签条和“显示标签页”入口，先恢复官方分屏，聊天身份稳定750ms后才跟随；空面板走“新建标签页→更多工具”，菜单采用可取消的 Enter 激活，过滤隐藏/离屏/被遮挡同名控件；等待切换中的短暂无身份，并在插件选中后再次确认分屏与连续两次选中状态；手动成功后只在主聊天身份变化时恢复，唯一实际可命中的控件、限时等待、身份复核、切换取消后继续跟随、单聊天失败停止重复尝试及销毁取消；不读正文、不走私有 IPC 或浏览器替代。
- `page-context.js`：记录最近操作的主聊天或标签页，识别模态窗口及已验证的独立聊天容器，供停靠与输入目标校验共用；普通非模态注释/编辑浮层不改变停靠目标。
- `context.js`：mainChatSessionId 复用现有明确聊天标记并拒绝多主聊天歧义，不受阅读锁定影响；聊天/回答/输入目标识别、上下文与流式状态；集中选择器与正文解析，完整采集相邻用户问题。
- `composer.js`：输入框操作与发送就绪重试；每次重试核对调用意图及聊天身份。
- `appearance.js`：只读适配 Codex 字体、主题与内容边界，不切换宿主主题。
- `association.js`：跟随/锁定/改锁来源的受限操作；来源文字与菜单暂时隐藏，保留状态与失联反馈，不保存容器布局。
- `outline.js`：本地大纲解析、刷新及真实聊天定位；编号伪标题允许正文内部空格，兼容单个汉字或英文单词后接混排内容；不依赖下一步，列表由 features/outline 渲染。
- `next.js`：建议生成协调、最近 32 次结果的内存缓存、普通/快捷词填入的草稿保护；缓存校验完整问答、聊天和生成配置，停用或配置变化清空。
- `model.js`：观察关联的官方 model/list 能力，优先识别输入区/祖先的稳定聊天身份，引用注释仅作为无权威身份时的回退；无消息区的新聊天以明确的官方输入区实例建立临时目标，不持久化、不继承路由或引用身份，输入区替换或身份建立使旧操作失效；提供宿主可见性/焦点，经官方菜单执行并回读；支持独立子菜单、内联选项、simple/advanced同根视图、显式模型后的推理滑块及Fast复选项/速度飞出菜单；从菜单内读取模型名、从可访问标签读取速度，关闭后记录稳定缓存，已选高级项可返回简洁视图；显式操作附有界无正文阶段诊断；先记录菜单归属再解析，失败清理自身菜单；旧目标、冲突、官方控件禁用或能力未知时拒绝切换；生成状态不单独阻塞；有界事务可取消，部分完成明确报告。
- `LICENSE.model-deck`：Model Deck 原始 MIT 许可，分发保留署名。
- [runtime/AGENTS.md](runtime/AGENTS.md)：注入集成入口、分域状态、设置同步与窗口投影。

context 管理跟随/锁定与唯一来源重绑，锁定失联不回退其他来源。page-context/context 排除自有功能根，避免将任务编辑框识别成聊天；输入框在消息区旁边时，仅扩展到包含唯一聊天的最近容器。模型能力未知、目标冲突或官方控件禁用时拒绝切换。

旧模型专用 UI 已退出；模型功能由 features/model 提供，/model-control 兼容 URL 转至设置页。model.js 仍是实际官方菜单适配器，不是可删除的旧窗口。

显式模型刷新在列表为空时最多等待 3.5 秒的关联能力响应，然后回读当前配置；无响应明确失败并清理自有菜单，仍受 11 秒事务截止限制。被动轮询不打开菜单、不主动发起 model/list 请求。同一 document 内重装适配器接续已验证的模型能力字段，不继承当前选择、请求关联或修订号；新 document 重新观察，不持久化能力缓存。

[PROTOCOL]: 结构、职责或接口变化时更新本文；父级描述受影响时同步父级地图。

plugin-tab.js 的 openSettingsBrowser 仅接收本机 HTTP 地址，经当前聊天的可见新标签页与浏览器地址栏导航，并恢复分屏；目标变化、重复入口或缺少地址栏时报错，不降级到外部浏览器，不记录 URL 令牌。

内置浏览器打开前显式展开隐藏的标签栏；新建后等待地址栏，不重复点击同一个 New tab。该浏览器适配与保留的插件实验同文件，但不依赖 MCP 或插件安装。

- `prompt-enhancement.js`：在已确认输入区工具栏挂载优化/取消/还原，复用composer原始文本读取与受控写入。仅保存当前操作的临时原文、DOM与签名；输入变化/IME/会话变化/销毁取消，迟到结果不可覆盖；复杂引用节点拒绝替换，错误行内展示。

model.js增加只读inputTarget()，复用唯一聊天身份与最近操作归属，不依赖模型能力/菜单触发器；已有snapshot/apply仍要求模型触发器。

提示词优化入口位于当前输入框右侧语音/发送操作同排，避开模型选择器的折行容器。按钮只显示PencilSparkle图标，与原生按钮同高；处理中为取消图标，完成后同一个按钮变为还原图标，回退后恢复优化，编辑后旧备份失效并恢复优化图标，无文字标签或Tooltip，保留aria-label。

codex-host.js通过上游版本化只读探针按输入框确认Agent；非Codex或缺失/未知状态拒绝官方模型写入，不触发上游菜单。cdp在model.js前安装，提示词优化保留独立输入目标识别。
