# ui/codex/ — Codex 页面适配

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

读取和操作 Codex 页面，保留必须在浏览器环境执行的逻辑。context/composer 不依赖功能视图；outline/next 协調现有业务状态与受限后台请求，呈现交给 ui/features。

- `page-context.js`：记录最近操作的主聊天或标签页，识别模态窗口及已验证的独立聊天容器，供停靠与输入目标校验共用；普通非模态注释/编辑浮层不改变停靠目标。
- `context.js`：聊天/回答/输入目标识别、上下文与流式状态；集中选择器与正文解析，完整采集相邻用户问题。
- `composer.js`：输入框操作与发送就绪重试；每次重试核对调用意图及聊天身份。
- `appearance.js`：只读适配 Codex 字体、主题与内容边界，不切换宿主主题。
- `association.js`：跟随/锁定/改锁来源的受限操作；来源文字与菜单暂时隐藏，保留状态与失联反馈，不保存容器布局。
- `outline.js`：本地大纲解析、刷新及真实聊天定位；不依赖下一步，列表由 features/outline 渲染。
- `next.js`：建议生成协调、最近 32 次结果的内存缓存、普通/快捷词填入的草稿保护；缓存校验完整问答、聊天和生成配置，停用或配置变化清空。
- `model.js`：观察关联的官方 model/list 能力，优先识别输入区/祖先的稳定聊天身份，引用注释仅作为无权威身份时的回退；提供宿主可见性/焦点，经官方菜单执行并回读；支持独立子菜单、内联选项、simple/advanced同根视图、显式模型后的推理滑块及Fast复选项/速度飞出菜单；从菜单内读取模型名、从可访问标签读取速度，关闭后记录稳定缓存，已选高级项可返回简洁视图；显式操作附有界无正文阶段诊断；先记录菜单归属再解析，失败清理自身菜单；旧目标、冲突、官方控件禁用或能力未知时拒绝切换；生成状态不单独阻塞；有界事务可取消，部分完成明确报告。
- `LICENSE.model-deck`：Model Deck 原始 MIT 许可，分发保留署名。
- [runtime/AGENTS.md](runtime/AGENTS.md)：注入集成入口、分域状态、设置同步与窗口投影。

context 管理跟随/锁定与唯一来源重绑，锁定失联不回退其他来源。page-context/context 排除自有功能根，避免将任务编辑框识别成聊天；输入框在消息区旁边时，仅扩展到包含唯一聊天的最近容器。模型能力未知、目标冲突或官方控件禁用时拒绝切换。

旧模型专用 UI 已退出；模型功能由 features/model 提供，/model-control 兼容 URL 转至设置页。model.js 仍是实际官方菜单适配器，不是可删除的旧窗口。
