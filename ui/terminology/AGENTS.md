# ui/terminology/ — 术语标注

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

- `matcher.js`：中文名称、英文名称、别名的最长优先字面匹配；英文边界、歧义别名和已掌握过滤。
- `card.js`：选定的贴字浮层内容与操作；中文/英文同排，使用 codex/typography 的字体、字重、行高与布局缩放快照；释义首行缩进2em、标题后6px小间距，底部左侧以正文75%字号（最低11px）显示真实分类路径，放不下自然换行，无悬停提示（无分类时隐藏）与右下角收藏/已掌握图标，独立保存反馈与动作动画。
- `host.js`：复用 codex/context 的活动根节点与一问一答；CSS Highlight 标注、跨节点范围、悬停加深高亮、按当前行鼠标位置锚定浮卡（移入卡片时保持位置）、键盘替代、语义分析身份和生命周期回收。禁止写聊天或读取输入框草稿；不包装/替换宿主文字节点。

宿主语义识别和联网自动积累由独立后台执行，HTTP 只查询短术语；材质选择位于设置页功能分类。词库存在私有数据目录，不提交完整词典。主聊天生成与术语分析不共享对话历史。

[PROTOCOL]: 变更时更新此头部，然后检查 AGENTS.md。

- `text-ranges.js`：规范化空白并映射回原始文字节点，支持跨段、跨行及加粗文字定位；排除代码、编辑器与自有界面。
host 的词条集合包含已掌握词，绘制时才过滤；结果按问答缓存32项，失败最多三次且间隔30秒，后台显示阶段。当前聊天上报验证宿主身份与当前context，切换后旧结果不得记入新聊天。卡片收藏与已掌握采用共享图标、独立回调和Tooltip，收藏失败不显示成功状态。

- `popover.js`：正文与侧栏共用的视口定位、可中断淡入淡出、互斥浮层、外点/Escape 关闭和资源回收。
- `appearance.js`：读取 Buddy 语义主题，复用原材质与 SVG 液态渲染；支持哑光、磨砂、液态 Regular/Clear、纯黑和自定义背景，保留旧 plain/frost 偏好兼容。

正文与侧栏通过宿主只读 typography 快照共享当前聊天排版，CSS zoom 补偿包含卡片宽度、留白与按钮；浮层按缩放后的尺寸避让屏幕边缘。宿主字体/缩放变化时同步更新，不修改宿主。

语义模式仅绘制当前聊天已核对的原句范围，本地名称匹配不直接显示；关闭语义时保留显式字面模式。缓存按问答和聊天隔离，词库变化重新核对；失败不恢复未核对词义。observe 分开累计语境确认编号，旧字面记录保留但不混入确认列表。

生成中允许分析宿主明确标记 complete 的已完成问答；不能用全局 busy 取消上一轮的稳定快照，仍按聊天/根节点/问答身份拒绝迟到结果。
