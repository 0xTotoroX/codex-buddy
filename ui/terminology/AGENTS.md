# ui/terminology/ — 术语标注

> L2 | 父级：[AGENTS.md](../../AGENTS.md)

- `matcher.js`：中文名称、英文名称、别名的最长优先字面匹配；英文边界、歧义别名和已掌握过滤。
- `card.js`：简洁白卡、磨砂卡共用的安全文本呈现；操作分别更新收藏和已掌握状态。
- `host.js`：复用 codex/context 的活动根节点与一问一答；CSS Highlight 标注、跨节点范围、悬停轮廓、键盘替代、语义分析身份和生命周期回收。禁止写聊天或读取输入框草稿；不包装/替换宿主文字节点。

宿主语义识别和联网自动积累由独立后台执行，HTTP 只查询短术语；样式选择位于设置页功能分类。词库存在私有数据目录，不提交完整词典。主聊天生成与术语分析不共享对话历史。

[PROTOCOL]: 变更时更新此头部，然后检查 AGENTS.md。

- `text-ranges.js`：规范化空白并映射回原始文字节点，支持跨段、跨行及加粗文字定位；排除代码、编辑器与自有界面。
host 的词条集合包含已掌握词，绘制时才过滤；结果按问答缓存32项，失败最多三次且间隔30秒，后台显示阶段。当前聊天上报验证宿主身份与当前context，切换后旧结果不得记入新聊天。卡片收藏与已掌握采用共享图标、独立回调和Tooltip，收藏失败不显示成功状态。
