# ui/panel/workbench/ — 停靠工作台

> L2 | 父级：[AGENTS.md](../AGENTS.md)

一个外壳同时呈现大纲与 Stepwise，复用现有业务状态和原生弹出协议。支持已识别的 Codex 主内容和独立打开的前景聊天；自有界面挂载在占位内部，不在宿主顶层覆盖。设置/未知对话框出现时暂时让位，关闭后恢复；不向侧边聊天内部挂载。旧偏好继续采用胶囊，用户主动切换工作台。

- [layout.js](layout.js)：占位适配生命周期、停靠开合与布局选择；宽度、比例通过既有偏好同步保存，与浮窗宽高分开。
- [reading.js](reading.js)：迁移前保存有限的临时阅读状态，按聊天和内容身份恢复，不写入配置或缓存正文。
- [view.js](view.js)：双面板增量渲染、独立滚动、上下分隔线和侧栏调宽、来源标签、设置覆盖页；不生成第二套业务运行时。
- [styles.css](styles.css)：工作台专用布局与分隔线；共用三种材质，不修改宿主样式。

侧栏宽度 300–460，默认 340；主聊天至少保留 560。空间不足收为非遮挡入口，空间恢复不自动打开。两块内容区连同标题各至少 180；分隔线支持方向键。设置暂时覆盖双面板，返回保留阅读位置。禁用的功能显示关闭状态，不自动开启或请求模型。

[PROTOCOL]: 变更时更新本文，然后检查父级 AGENTS.md。

主窗口和前景聊天空间不足都不修改用户的开合偏好；可适度缩窄前景聊天实际栏宽，保存宽度保持原值。临时收起由宿主适配记录，空间恢复后仍需主动打开。迁移和临时让位保留阅读位置，关闭前景聊天后恢复主聊天。停靠态共用宿主外框，只保留分隔线；独立浮窗材质和外框不变。
