# ui/panel/workbench/ — 停靠工作台

> L2 | 父级：[AGENTS.md](../AGENTS.md)

一个外壳同时呈现大纲与 Stepwise，复用现有业务状态和原生弹出协议。支持已识别的 Codex 主内容和独立打开的前景聊天；自有界面挂载在占位内部，不在宿主顶层覆盖。设置/未知对话框出现时暂时让位，关闭后恢复；不向侧边聊天内部挂载。旧偏好继续采用胶囊，用户主动切换工作台。

- [model.js](model.js)：内置面板尺寸/身份注册表与默认打开列表分离，旧比例迁移、实际容器上的分栏决策及菜单/拖拽共用的纯编排命令；自动模式使用 32px 滞回，不保存临时回退。
- [layout.js](layout.js)：占位适配生命周期、共用胶囊发起的停靠开合与位置选择（切到内嵌浮动可保持展开），收起前保存表情位置和阅读状态；宽度、比例通过既有偏好同步保存，与浮窗宽高分开。
- [arrangement.js](arrangement.js)：面板标题/标签拖拽、落位预览与取消、保留隐藏编排处理器、标签键盘导航和不持久化的专注查看；有效松手才提交，失焦/缩窗/上下文变化撤销预览，不发送窗口拖动或业务请求。
- [reading.js](reading.js)：迁移前保存有限的临时阅读状态，按聊天和内容身份恢复；隐藏标签及布局扩容时保留被浏览器夹紧的滚动意图，真实滚动更新位置，不写入配置或缓存正文。
- [association.js](association.js)：工作台来源文字和跟随/锁定/改锁当前聊天菜单暂时隐藏但保留状态、处理器及失联提示；本地调用宿主策略，浮窗复用受限命令，不扫描聊天或保存布局。

- [view.js](view.js)：双面板增量渲染、独立滚动、自动/上下/左右排列、交换与重置、双向分隔线和侧栏调宽、标签组/专注显示、隐藏来源标签、居中表情、精简的窗口往返/内嵌收起按钮、设置覆盖页；不生成第二套业务运行时。
- [styles.css](styles.css)：工作台专用布局与分隔线；顶部操作/刷新局部悬停或键盘聚焦显现，触屏保持可见；共用三种材质，不修改宿主样式。

侧栏宽度 300–460，默认 340；主聊天至少保留 560。主动收起或空间不足均回到共用胶囊并释放占位，空间恢复不自动打开。两块内容区连同标题各至少 180；左右模式中大纲至少 220、下一步至少 260。分隔线按实际方向响应方向键。停靠与浮窗分别保存 group（split/tabs）、active、mode、first、verticalRatio、horizontalRatio；交换时保留面板面积，旧 splitRatio 迁移至两端上下比例，后续作为停靠上下比例的兼容字段。设置暂时覆盖双面板，返回保留阅读位置。禁用的功能显示关闭状态，不自动开启或请求模型。

聊天关联与编排独立，两面板共用来源；锁定失联保留可读内容，禁用刷新和定位。隐藏期间不以零尺寸滚动值覆盖已有阅读记录。

工作台也是浮动胶囊展开与桌面浮窗的唯一展开外壳；layoutMode 保留历史位置偏好，不再选择不同展开界面。公共头部在分栏、标签、专注和设置时始终保留共享表情及收回按钮，表情不属于业务面板。退出停靠回到紧凑胶囊；未识别宿主不能以覆盖式工作台冒充停靠。

[PROTOCOL]: 变更时更新本文，然后检查父级 AGENTS.md。

主窗口和前景聊天空间不足都不修改用户的开合偏好；主窗口与前景聊天均可适度缩窄实际栏宽，保存宽度保持原值。临时收起由宿主适配记录，空间恢复后仍需主动打开。迁移和临时让位保留阅读位置，关闭前景聊天后恢复主聊天。停靠态共用宿主外框，只保留分隔线；独立浮窗材质和外框不变。

窗内编排只支持已有两个面板：保留稳定 DOM，边缘落点形成手动分栏，中央合并标签。自动布局只调整分栏方向，不拆标签；空间不足不自动合并，无法容纳的分栏命令禁用。标签使用手动激活的方向键焦点导航，隐藏面板 inert；首项决定标签顺序，恢复默认回到自动双面板。专注查看仅在当前视图实例存储，Esc 或双击标题恢复；标题支持 Enter/空格，期间禁用编排；冷启动、跨呈现交接不保存临时专注。

公共表情为 84×46，头部两侧等宽、中心独立；与浮动胶囊的形变终点一致，过渡时不隐藏动画表情。顶部隐藏来源文字，保留居中表情、移到独立窗口/放回聊天、内嵌收起与设置；设置使用返回箭头。面板只保留刷新按钮，标题/标签拖动编排、双击临时放大；编排和布局菜单暂时隐藏且保留处理器，完整排列、位置、置顶与明暗在 Web 设置中。不再用切回胶囊同时改变位置和开合。胶囊恢复停靠偏好；空间不足时点击显示原因，并提供明确的独立窗口/聊天内展开选项，聊天内展开一步完成而非先退回胶囊。控制 SVG 均来自共享 icons。
